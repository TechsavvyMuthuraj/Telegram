Privacy Policy

Last updated: October 2026 • Effective for Techi Files & @TechiePostManagerBot

1. Overview

This Privacy Policy explains how Techi Files and the Techie Post Manager Telegram Bot (@TechiePostManagerBot) operate in full compliance with privacy standards and community safety guidelines managed by @techiemuthuraj.

2. Information We Process

We believe in minimal data footprint. We only process data required to deliver requested digital files and authenticate legitimate channel subscribers:

  • Telegram Identity: User ID, username, and public display name provided via Telegram Bot API when verifying channel membership.
  • Access Tokens: Cryptographically hashed tokens (`TM-XXXX...`) used to unlock verified files.
  • IP Hashes: For DDoS mitigation and rate-limiting, IP addresses are irreversibly hashed with cryptographic salt (SHA-256). Plain IP addresses are never permanently retained.
  • Channel Post Drafts: Content drafts composed by authorized administrators are stored temporarily to facilitate multi-step publishing.

3. Third-Party Services & Infrastructure

Our service runs on secure, isolated cloud architecture:

  • Telegram Bot API: For chat command delivery, inline menus, and channel broadcasting.
  • Supabase PostgreSQL: Enterprise-grade encrypted database hosting for file catalog metadata.
  • Netlify Serverless: HTTPS-encrypted edge execution with strict security headers.

4. Data Retention & Deletion

Users have the right to request deletion of access history at any time. Administrators have real-time controls in the Admin Console to purge logs, reset counters, and delete inactive sessions with one click.

5. Contact & Support

If you have any questions regarding privacy or data handling, contact us via Telegram at @techiemuthuraj or visit techsavvymuthuraj.dev.
