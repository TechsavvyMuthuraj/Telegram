ℹ️ Telegram Bot API Technical Limits

  • 20 MB File Download Limit: The standard Telegram Bot API (via getFile) only permits programmatic downloads of files up to 20 MB. Files over 20 MB cannot be streamed through standard bot endpoints.
  • Workaround for Large Files (>20 MB): Upload large files to cloud storage (e.g. Cloudflare R2, Supabase Storage, Google Drive, AWS S3) and enter the direct URL, or provide the direct channel message link which users can open in Telegram desktop/mobile.
  • Bot Channel Permissions: Ensure your bot is added as an Administrator to your Telegram channel with at least "Post Messages" and "Manage Channel" capabilities.
